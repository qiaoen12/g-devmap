# 任务来源示例（可选）

下面是推荐写法，不是解析依赖。已有 Issue、PRD、笔记或聊天内容可以直接使用，不需要改写成固定字段。

## Background

任意背景、需求、约束、验收或其他说明。这一节可以不存在；没有它也不影响后面的执行计划。

## Execution

可复用执行计划。内部结构见 [execution-plan.md](execution-plan.md)。那是本区块的数据说明，不是整个任务来源的模板。

没有精确标题 `## Execution` 时，DevMap 根据现有素材和相关仓库事实自行规划。地图默认只出现在当前 Harness 对话。不自动写入 GitHub Issue comment、PR comment 或其他远端位置。只有用户明确要求保存时，才写用户指定的载体或路径。

计划是可复用的静态专业数据；状态、实际文件、测试结果、阻塞及事件历史保留在当前 Runtime。原始素材不自动改写。默认地图只投影简短名称、状态、文件摘要与验证摘要。
