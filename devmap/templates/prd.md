# 需求素材（可选）

已有 Issue / PRD 直接读取，不要求套用本模板。信息足够时 Agent 自行规划；只有缺失信息会改变最终结果时才向负责人反问。

- 目标与预期结果：希望完成后具有什么行为。
- 范围与边界：包含什么、不包含什么。
- 已知约束与业务决定：已有决定与会改变结果的缺口。
- 验收要求：如何确认结果成立，包括最终验收。
- 已有 Execution Plan（可选）：完整数据或可访问引用。

## Agent 的规划输出

使用唯一的 [Execution Plan 模板](execution-plan.md)。有计划时先轻量检查并复用；无计划时读需求与相关当前仓库事实，形成 Approach、Tasks 与验证。不要在此维护第二份 Task schema，也不要求用户将旧 Issue 改写为固定模板。

计划是可复用的静态专业数据；状态、实际文件、测试结果、阻塞及事件历史保留在当前 Runtime。原始素材不自动改写；保存须使用用户指定路径。默认地图只投影简短名称、状态、文件摘要与验证摘要。
